# 來源前端交付驗證紀錄

日期：2026-09-12。以下是搬入本 repo 並轉成 Next.js App Router 前，來源版本的驗證紀錄；目前版本請以根目錄的 `npm test` 與 `npm run build:application` 為準。

## 結果

- TypeScript 與 production build 通過。
- 20 個服務／狀態單元測試全部通過。
- 5 組瀏覽器測試全部通過，合計 16.8 秒。
- 首頁與手機版已實際檢視。
- 建置後的 JavaScript 掃描確認，不含移除的提示字樣或預填測試個案。

## 流程測試

完整「同意書 → 填寫 → 檢視 → 收件 → 補件 → 評估安排」連跑三次。另涵蓋手動空白申請、必填驗證、資料授權、修改後重新確認、服務項目保存、重新整理恢復、390px 手機／鍵盤導覽及跨分頁事件更新。

新增介面文字檢查涵蓋首頁、申請、查詢、收件、補件及舊控制台路由。`/admin` 與 `/admin?demo=1` 均回找不到頁面；導覽沒有相關入口，使用者頁面不顯示開發狀態 JSON。

測試個案及事件由測試程式建立，不需要網站內的管理頁。測試資料未打包到 production JavaScript。

## 測試限制

本版尚未接上 HTTP 後台、登入或政府系統，驗證的是目前前端與本機資料服務。後台串接後，需重新驗證非同步請求、權限、409 衝突、重試／防重複送出和跨使用者資料更新。

身分證／居留證欄位為基本格式驗證，不代表完成身分核實。未宣稱正式無障礙認證或業務省時成效。
